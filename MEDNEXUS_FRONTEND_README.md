# MedNexus Frontend

## Run
```bash
cd ladybirdltd-svelte-main/ladybirdltd-svelte-main
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Implemented screens
- MedNexus welcome / role selection
- Individual dashboard
- ASHA worker dashboard
- ANM worker dashboard
- Symptom screening
- Severity result and referral guidance
- Health education
- Reports and screening trend
- Emergency SOS screen
- Profile and settings menu

## Custom logo
The supplied MedNexus logo is used at:
`static/images/mednexus-logo.png`
